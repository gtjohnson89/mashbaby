# mashbaby

Toddler keyboard-mash games. Open `index.html` in a browser (or serve the folder) and pick a game.

## Babies Eating Cookies

1. Click **Play Full Screen**
2. Mash any keys — cookies drop on the pan, grow, brown, and ding when ready
3. Babies crawl in, munch, and crawl off
4. Parent exit: hold **Esc** for 2 seconds (or long-press the tiny Exit button)

Sounds are synthesized in the browser (Web Audio) — no downloads needed.
